

"Prier avec les écritures" est un blog de prière interactif qui permet aux utilisateurs de méditer et de proclamer la Parole de Dieu sans avoir à créer de compte.

Principe : L'utilisateur sélectionne une Partie (ex: "Ma position en Christ") puis un Thème spécifique à l'intérieur de cette partie.

Contenu pour chaque thème : Une fois le thème choisi, le blog affiche une structure complète et prête à être utilisée pour la prière :

Les références bibliques qui fondent le thème.

Une confession de foi pour déclarer ce que l'on croit.

Une déclaration spirituelle pour affirmer la vérité sur sa vie.

Une proclamation d'autorité pour exercer l'autorité reçue en Christ.

Une prière à réciter ou à utiliser comme modèle.

Une progression spirituelle pour grandir dans cette réalité.

Objectif : Le blog est conçu comme un recueil de prières et de proclamations bibliques pour aider les croyants à s'approprier les promesses de Dieu, à renforcer leur identité en Christ et à marcher dans la victoire spirituelle.
